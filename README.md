# JN C Crate

Research, design and build an alternative to Music League (a social music game: themed rounds, song submissions, anonymous voting). Research first, then product.

**Status:** initialized 2026-11-22; nothing built yet.

| Folder | What is there |
|---|---|
| `research/` | Market and platform studies, one file per study |
| `tasks/` | Working memory: plan (`todo.md`), lessons, session handoffs |
| `knowledge/architecture/` | Decision log of this node |
| `inbox/` | Material arriving from other nodes or the web; read, never executed |
| `outputs/` | Finished work leaving this node, one subfolder per workstream |
| `logs/` | Cold history, searched with `grep` |

Agents read `AGENTS.md` (Claude Code reaches it through `CLAUDE.md`).
